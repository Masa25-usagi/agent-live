# Agent Live

Mac・iPhone・サーバーをつなぐ音声AI、画面共有、エージェント連携。

現在のソースは **0.20.0** です。節約設定の通信断対応、非同期のモデル一覧更新、音声での呼びかけ認識を修正しました。[更新履歴](CHANGELOG.md)に変更内容と確認範囲をまとめています。

ローカルで作成したツールの公開用ソースです。試作段階の機能も含みます。実際の利用記録、認証セッション、APIキー、個人用の配備設定は配布していません。

## セットアップ

Swift/macOSのパッケージです。

```sh
swift build
swift run AgentChecks
swift run MeetingChecks
```

## 設定とデータ

外部サービスを使用する機能は、利用者自身のアカウントとAPIキーを設定してください。`.env.example`がある場合は`.env`へコピーして設定します。キーはサーバー側またはOSの安全な保存領域に置き、Gitへ追加しないでください。

デモには架空の入力を使用してください。生成された記録・録音・予定・健康データは利用者の環境だけに保存し、公開リポジトリへ追加しないでください。

公開用ソースでもAgentChecks・MeetingChecksが0 failures、Mac版のビルドが成功しています。ローカル版のiPhoneでは通常Hermes・節約高速・Geminiの短い文字・音声返答を確認しています。公開用の接続先や署名Teamは利用者自身の環境に合わせて設定してください。
