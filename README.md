# Agent Live

Mac・iPhone・サーバーをつなぐ音声AI、画面共有、エージェント連携。

ローカルで作成したツールの公開用ソースです。試作段階の機能も含みます。実際の利用記録、認証セッション、APIキー、個人用の配備設定は配布していません。

## セットアップ

Swift/macOSのパッケージです。

```sh
swift build
swift run MeetingChecks
```

## 設定とデータ

外部サービスを使用する機能は、利用者自身のアカウントとAPIキーを設定してください。`.env.example`がある場合は`.env`へコピーして設定します。キーはサーバー側またはOSの安全な保存領域に置き、Gitへ追加しないでください。

デモには架空の入力を使用してください。生成された記録・録音・予定・健康データは利用者の環境だけに保存し、公開リポジトリへ追加しないでください。

## 配備

接続先はアプリ設定で指定します。更新スクリプトには`--ssh USER@HOST`を明示してください。Google Driveの認可は利用者自身のOAuthクライアントを使用し、`--local`または`--ssh`で保存先を選びます。
